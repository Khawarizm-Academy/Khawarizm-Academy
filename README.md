# خوارزم أكاديمي | Khawarizm Academy

> منصة تعليمية عربية (RTL) تربط بين **الدورات التدريبية** و**المنح الدراسية والفرص الدولية** على قدم المساواة، بنظام تصميم كوني مميز.

## 🧭 نظرة عامة

أكاديمية خوارزم هي منصة تعليم إلكتروني عربية أولاً (RTL) مبنية على فلسفتين متساويتين في الأهمية:

1. **الدورات التدريبية** – دروس مسجلة بالفيديو → تمارين عملية → مراجعات أسبوعية مباشرة → اختبارات شاملة
2. **المنح الدراسية والفرص الدولية** – تجميع وانتقاء المنح والفرص الأكاديمية الخارجية (لا تمنحها الأكاديمية نفسها، بل تعلن عنها وتنظم الوصول إليها)

كما تتضمن المنصة **فعاليات وندوات**، **مسابقات** (بما في ذلك مسابقات البرمجة)، وأدوات مساعدة متنوعة للمتعلمين.

- **[Radix UI](https://www.radix-ui.com/)** – مكونات وصولية غير مُصممة مسبقًا
- **[Motion](https://motion.dev/)** – حركات رقيقة ومتناسقة مع هوية المنصة
- **[Lucide React](https://lucide.dev/)** – أيقونات متناسقة

## ✨ أبرز المزايا

- **عربي أولاً مع دعم كامل RTL** – اتجاه كامل من اليمين لليسار مع استخدام الخصائص المنطقية في CSS
- **تناسق بصري كوني** – نظام ألوان مستوحى من الفضاء (Navy + Cyan + Gold) مع ظلال وهالات مميزة
- **سلة مهام موحدة** – كتالوج واحد يخدم الدورات والمنح مع مرشحات سياقية وعرض مختلط
- **ذاكرة تخزين مؤقت ذكية** – نظام SWR يقلل من الوميض ويُحافظ على سرعة التنقل
- **انتقالات صفحة ناعمة** – View Transitions API مع حفظ موضع التمرير
- **تحميل تدريجي (Lazy Loading)** – تقسيم الشفرات حسب المسار لتحميل أسرع
- **مظهر مطابق للأجهزة** – تصميم متجاوب للكمبيوتر والهاتف مع قوائم تنقل منفصلة
- **أداء عالي** – React Compiler + Vite يحافظان على تجربة سلسة

## 🚀 البدء السريع

### المتطلبات

- [Node.js](https://nodejs.org/) إصدار 18.0 أو أحدث
- [npm](https://www.npmjs.com/) أو [pnpm](https://pnpm.io/) أو [yarn](https://yarnpkg.com/)

### التثبيت والتشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/your-username/Khawarizm-Academy.git
cd Khawarizm-Academy/frontend

# 2. تثبيت التبعيات
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

سيفتح التطبيق على `http://localhost:5173` افتراضيًا.

### أوامر مفيدة

| الأمر | الوصف |
|---|---|
| `npm run dev` | تشغيل خادم التطوير مع إعادة التحميل الفوري |
| `npm run build` | بناء الإنتاج (TypeScript + Vite) |
| `npm run preview` | معاينة بناء الإنتاج محليًا |
| `npm run lint` | فحص الشفرات بـ ESLint |
| `npm run brand:generate` | توليد أصول العلامة التجارية من الشعار الرئيسي |

## 🏛️ هندسة الواجهة الأمامية

### بنية المجلدات

```text
frontend/src/
├── app/                # إعدادات التوجيه، التخطيط، والتحكم في الروتين
├── features/           # وحدات الميزات المستقلة (courses, catalog, dashboard...)
│   ├── catalog/       # الكتالوج الموحد مع الفلاتر السياقية
│   ├── dashboard/     # لوحة التحكم الشخصية
│   ├── home/          # الصفحة الرئيسية
│   ├── auth/          # المصادقة
│   └── ...
├── shared/             # مكونات، hooks، مكتبات مساعدة مشتركة بين الميزات
│   ├── components/    # مكونات قابلة لإعادة الاستخدام
│   ├── hooks/         # useCachedData, useCountdown...
│   ├── lib/           # cacheManager, navigation, localization...
│   ├── json/          # بيانات ثابتة (مسارات، قوائم، ترجمات)
│   └── types/         # أنواع TypeScript المشتركة
├── styles/             # توكنات التصميم وCSS عام
└── mocks/              # بيانات تجريبية حتى ربط الواجهة بالخلفية
```

**قاعدة مهمة:** ميزة معينة لا تستورد من داخل ميزة أخرى مباشرةً. إعادة الاستخدام تمر عبر `shared/` فقط.

### أنماط التصميم المتبعة

- **بيانات ثابتة** → توضع في `src/shared/json/`، ما عدا ما هو ضروري فقط لملف معين
- **فصل الاهتمامات** → كل ميزة تحوي مكوناتها، أنواعها، وبياناتها الخاصة
- **عدم تكرار** → أي نمط يظهر في أكثر من مكان يُستخرج لمكون مشترك أو لفئة CSS مفهوم
- **RTL أولاً** → استخدام الخصائص المنطقية (`ms-*`, `me-*`, `start-*`, `end-*`)
- **توكنات التصميم** → جميع الألوان، المسافات، والظلال تأتي من `styles/tokens.css`
